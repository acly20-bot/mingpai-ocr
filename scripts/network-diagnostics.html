铭牌识别 · 国内网络对照测试

分别向 GitHub Pages 和腾讯云 COS 请求同一份文件，检查当前手机网络实际是否能读取。测试过程不修改正式版、测试版、设备记录或飞书数据。

测试前说明

建议在国内手机、不使用 VPN的情况下测试。首次测试尽量使用新浏览器，或清除这个测试页的站点缓存；不要清除铭牌识别正式版的数据。

每项测试均主动绕过 HTTP 缓存；但 CDN、运营商线路、跨域策略仍会影响结果。测试只会在你点击按钮时下载资源，不会自动下载几十 MB 的文件。

怎样判断结果

如果 GitHub 和 COS 均能读取小规则 JSON，可以继续让 JSON 留在 GitHub；但要多测试几台国内手机和不同网络。若 GitHub 大 JS 或 WASM 慢、超时而 COS 正常，就应继续保持主程序和 WASM 在 COS。

如果出现“跨域/CORS 或网络失败”，不能仅凭这一次判定国内网络不通：这也可能是 COS 的跨域设置或浏览器隔离策略导致。单纯在地址栏打开后提示下载，不等于网页能够正确执行它。

本页测试能证明什么，不能证明什么？

本页检测下载成功率、完整字节数及耗时；不执行 OCR，也不测试 WebGPU、Worker 初始化、COEP/CORP 或模型运行。正式变更服务器前，还需要测试实际页面完整识别 9 张、断网恢复和首次打开。
